# CABINET & CO.: Victorian shop

DesignKit 2.0.0. Original fictional example, reusable under MIT; bundled fonts retain their original OFL licenses.

## Project context

Printed curiosities, considered keepsakes, and small editions for a well-loved shelf.

Headline: Objects with a story to tell.

The primary action: Explore the collection

## Design reasoning

### Composition

Ornamental product framing suggests a cabinet while shopping controls remain familiar.

### Material and geometry

Decorative framing and historic display character with contemporary reading clarity.

### Reading and interaction

Frame a clear central hierarchy with ornamental rules; reserve blackletter for short display moments. Keep ornament static and state changes direct; readable body type carries detailed information.

## Typography

Heading: Playfair Display
Body: Cormorant Garamond

Treat this pairing as an interpretation. If the destination project already has a suitable typeface, preserve it unless the requested direction needs a different voice.

## Content

## Adaptation

Frame a clear central hierarchy with ornamental rules; reserve blackletter for short display moments.

Keep ornament static and state changes direct; readable body type carries detailed information.

Use the page structure for its context, not as a universal template. Keep the user's real content and required interactions.

## Review

- Treating all nineteenth-century styles as identical.
- Blackletter for navigation or long paragraphs.
- Ornament that competes with the content.

Check reading order and text contrast at phone width; ensure native controls retain keyboard and focus feedback. Preview tasks, carts, and schedules are local demonstrations, not backend integrations.
