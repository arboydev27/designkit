# ODD OBJECTS: Maximalism shop

DesignKit 2.0.0. Original fictional example, reusable under MIT; bundled fonts retain their original OFL licenses.

## Project context

Playful prints and wonderfully unnecessary objects with a very necessary point of view.

Headline: Ordinary has left the building.

The primary action: Explore the collection

## Design reasoning

### Composition

Eclectic product frames share one consistent label and purchase system.

### Material and geometry

High visual density and eclectic contrast controlled by an unmistakable focal point.

### Reading and interaction

Give one loud message priority, then build a deliberate collage of type and shapes around it. Let explicit actions trigger brief feedback; multiple simultaneous loops would weaken the hierarchy.

## Typography

Heading: Syne
Body: DM Sans

Treat this pairing as an interpretation. If the destination project already has a suitable typeface, preserve it unless the requested direction needs a different voice.

## Adaptation

Give one loud message priority, then build a deliberate collage of type and shapes around it.

Let explicit actions trigger brief feedback; multiple simultaneous loops would weaken the hierarchy.

Use the page structure for its context, not as a universal template. Keep the user's real content and required interactions.

## Review

- Treating every element as the focal point.
- Layering text across busy patterns.
- Sacrificing reading order for visual density.

Check reading order and text contrast at phone width; ensure native controls retain keyboard and focus feedback. Preview tasks, carts, and schedules are local demonstrations, not backend integrations.
