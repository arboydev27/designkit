# Pixel art: DesignKit reference

Version 2.0.0. A contemporary interpretation of this direction. The three projects vary content, palette, and typography while preserving the style’s defining materials and composition. Treat suggested colors and typefaces as adaptable choices.

## Character

Pixel art builds images from deliberately placed pixels, often working within a limited palette and resolution. Crisp edges and repeated pixel units can extend from illustration into borders, icons, and interface details.

Pixel-aligned forms and nostalgic game language with modern interaction clarity.

- Crisp pixels
- Limited palettes
- Grid-built icons
- Stepped edges

## Three interpretations

### SIDEQUEST (event)

An independent games afternoon with tiny worlds, big ideas, and room for a new player.

Chunky schedule blocks feel game-like, while ticket selection follows familiar controls.

### CHECKPOINT (planner)

Break your project into small missions and keep track of what actually moved forward.

Pixel geometry frames ordinary tasks; a readable body face carries longer instructions.

### 8-bit supply (shop)

Small-run prints and objects inspired by worlds built one square at a time.

A crisp product grid prevents nostalgic display type from taking over every detail.

## Composition and behavior

Work with block geometry, crisp edges, and a coarse rhythm; pair pixel display lettering with readable body text.

Use discrete state changes rather than flickering sprites; never communicate a state through animation alone.

## Useful decisions

- Scale artwork in whole-number steps.
- Keep a consistent apparent pixel size.
- Use pixel lettering sparingly and generously sized.

## Common mistakes

- Blurring or stretching pixel assets.
- Tiny text in dense pixel fonts.
- Mixing several incompatible pixel grids.

## Suitability

- Indie games
- Retro communities
- Playful personal sites

Choose a relevant interpretation or compose a new one for the actual project. Do not turn a visual style into a requirement to use a particular page structure.
