# Bento grid: DesignKit reference

Version 2.0.0. A contemporary interpretation of this direction. The three projects vary content, palette, and typography while preserving the style’s defining materials and composition. Treat suggested colors and typefaces as adaptable choices.

## Character

Bento layouts arrange varied content into a modular family of rectangular tiles. Differences in size create hierarchy while shared spacing and alignment keep the collection coherent.

Modular composition, varied tile scale, and a coherent palette across independent content.

- Modular tiles
- Varied proportions
- Shared gutters
- Compact storytelling

## Three interpretations

### orbit. (planner)

A few useful modules for your tasks, notes, and the room you want to leave in your day.

Unequal planning tiles have separate purposes while their controls stay aligned.

## Composition and behavior

Use unequal modules in a stable grid; each tile has one purpose and a deliberate reading priority.

Animate a changed tile's content rather than moving the entire grid.

## Useful decisions

- Give every tile one clear purpose.
- Use tile size to express content importance.
- Plan the reading order before the mobile stack.

## Common mistakes

- Making all tiles equally loud.
- Packing unrelated material into one tile.
- Relying on desktop position to explain relationships.

## Suitability

- Product feature pages
- Personal dashboards
- Portfolio overviews

Choose a relevant interpretation or compose a new one for the actual project. Do not turn a visual style into a requirement to use a particular page structure.
