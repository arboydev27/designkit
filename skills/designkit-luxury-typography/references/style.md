# Luxury typography: DesignKit reference

Version 2.0.0. A contemporary interpretation of this direction. The three projects vary content, palette, and typography while preserving the style’s defining materials and composition. Treat suggested colors and typefaces as adaptable choices.

## Character

Luxury-oriented typography often uses expressive serifs, careful spacing, and a restrained supporting system to suggest refinement. The effect comes from proportion, art direction, and consistency rather than any single font or color.

Elegant display proportions, disciplined whitespace, and considered typographic detail.

- High-contrast serifs
- Careful spacing
- Restrained details
- Dramatic scale

## Composition and behavior

Treat large high-contrast type as the main image; maintain precise spacing and modest supporting controls.

Use restrained, brief transitions; never delay navigation to imply prestige.

## Useful decisions

- Use display serifs at sizes that preserve fine strokes.
- Adjust letter spacing for the actual text.
- Let photography and material details support the type.

## Common mistakes

- Tiny thin-stroked labels.
- Excessive tracking in body text.
- Assuming metallic color alone conveys quality.
